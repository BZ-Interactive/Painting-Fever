## 📖 About

Painting Fever is a 2D platformer that combines music‑driven gameplay with creative wall‑painting mechanics. Players sprint through dynamic levels, paint walls to create paths, and stay in sync with the beat.

## 🔍 Current Status

This game is in early development. Currently implemented features include basic platforming and movement mechanics.

## 🛠️ Features in development

- Pause menu
- Game end screen
- Wall painting mechanics
- Level progress system
- Music BPM action‑sync

## 🛠️ Built With

- Godot Engine 4.5.1 Mono (2D)

## 📦 Prerequisites

- Godot Engine 4.5.1 or later
- A modern web browser or Godot editor

## 📥 Installation

```sh
# Clone the repository
git clone https://github.com/${{GITHUB_REPOSITORY}}.git
cd $(basename ${PWD})
```
Open `project.godot` with the Godot editor and run the main scene.

## 🎮 Usage

Launch the game via the Godot editor or export for your platform.
Controls will be added here as they are finalized.
